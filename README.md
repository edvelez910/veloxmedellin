# Velox VIP Services

Sitio web estático de Velox VIP Services, listo para publicarse con GitHub Pages.

## Publicación

1. Sube el contenido de esta carpeta a la rama principal del repositorio.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama principal, la carpeta **/(root)** y guarda.

La entrada es `index.html`; no requiere compilación.

## Pendiente comercial

Antes de publicar, reemplaza las fotografías de muestra por imágenes propias de la flota y agrega los datos de contacto oficiales cuando estén confirmados.
